One emoji for one dream vacation: Mount Fuji (🗻, U+1F5FB) — a single code point, no words, written to `/output/entry.txt` by `main.ts` (Node 22, standard library only, no network). A snow-capped Fuji at a glance is a postcard: one specific, iconic place a stranger can picture booking a flight to, not a generic holiday sign. The output is deterministic: the same single emoji every run, written with no trailing newline, and the program throws if the entry is ever not exactly one emoji code point.

Entry: 🗻 (U+1F5FB MOUNT FUJI — 1 code point, UTF-8 bytes F0 9F 97 BB, no variation selector, no ZWJ)

## Run it

```sh
node main.ts
```
